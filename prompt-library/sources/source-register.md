# Source register

Research was reconciled on 2026-09-13. “Full repository review” means the checked-out repository, its documentation, prompt/data structures, representative prompt bodies, supporting schemas/scripts, and license files were inspected. It does **not** mean every item in a collection containing hundreds or thousands of near-duplicate prompts was individually copied or tested. The exact review evidence and adoption decisions are in [research-review.md](research-review.md); cross-source merges and exclusions are in [deduplication-ledger.md](deduplication-ledger.md).

## Interpretation rules

- A source preview demonstrates only that the source presented that prompt/result pair. It does not prove repeatability, causation, factual accuracy, or compatibility elsewhere.
- `verified` compatibility in this library means official documentation confirms the model/mode supports the operation—not that this particular template was run.
- Community model IDs, prices, limits, and “always/never” rules are rejected when stale, uncorroborated, or contradicted by current official documentation.
- Source text without an explicit content license is paraphrase-only. Aggregator repository licenses are not treated as blanket licenses over third-party prompt bodies.
- No source prompt was copied wholesale into the template library. Each entry states its own source-specific reuse decision.
