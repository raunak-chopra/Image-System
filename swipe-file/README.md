# Swipe file

Personal reference library (private repo, personal use). Drop documents of links or screenshots in `inbox/`; the agent goes through them and writes one breakdown per reference into `breakdowns/`, tagged in `index.csv`.

Breakdown fields: source link, category, format (e.g. amazon-gallery, meta-feed), layout grid, text hierarchy, type style, color logic, badge/icon treatment, hook, why it works, recipe it maps to.

Repeated patterns are promoted to `design-language/` recipes and then to templates in `prompt-library/`.
